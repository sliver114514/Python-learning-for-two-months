从零开始，用约两个月时间完成44个Python项目。每个文件都包含极其详细的中文注解。Beginner为基础项目，注解比较简洁；Intermediate为中级项目，注解更详细。

> **学习建议**：强烈建议新手在练习时关掉代码自动补齐功能，这有利于更好地理解代码底层逻辑。

本仓库旨在帮助各水平层次的 Python 学习者，从适合初学者的项目入手，逐步过渡到更高级的项目。编写项目需要一定的基础，至少要能理解较为简单的代码和关键词。如果你能坚持写完，你会感谢你自己。能坚持下来的你已经很了不起了。

##  关于这个仓库

这是一个记录我从 Python 零基础到能独立编写实用工具的完整历程。

**项目总数：** 44  
**入门级项目总数：** 32  
**中级项目总数：** 12

基于经典练习题进行实战，并加入了我自己的理解和改进：
- 为每一行代码添加详细中文注解
- 重构部分代码
- 增加输入验证和异常处理
- 按难度和主题重新组织文件结构

##  环境搭建

- 确保你的电脑上已安装 Python `3.6` 或更高版本（推荐使用 `3.12` 或更高版本）。
- 确保你有一个 IDE 或一个可以编写和运行 Python 解释器的环境。

##  如何使用

```bash
git clone https://github.com/sliver114514/Python-learning-for-two-months.git
cd Python-learning-for-two-months
```


> [!TIP]
> 我使用的是 PyCharm 来进行编写，它对新手极其友好。如果你有一定的基础，可使用 Visual Studio Code（VS Code）。它速度快、效率高，并且拥有丰富的扩展和自定义选项。

##  自学练习区（Self-Practice）

除了完成 44 个基础项目外，我还在 `Self-Practice/` 文件夹中记录了我的额外学习成果：

| 文件夹 | 内容 | 说明 |
| :--- | :--- | :--- |
| `modified/` | 魔改版 | 在原项目基础上修改核心逻辑，尝试不同的实现方式 |
| `optimized/` | 优化版 | 对原代码进行重构，增加异常处理、输入验证、现代写法 |
| `exercises/` | 杂项练习 | 学习过程中随手写的小练习、实验性代码 |

**为什么要单独放这些？**
因为学习编程不只是“照着写一遍”，更重要的是“改一改、试一试、玩一玩”。
这个文件夹记录了我从“跟着教程写”到“自己动手改”的成长轨迹。
